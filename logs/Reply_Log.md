# Reply_Log.md — one entry per reply, written the same turn

Timestamp, the question, bullets that stand alone — a searchable
long memory without keeping a verbatim chatlog. **Conventions:**
append-only, never rewritten (wrong entries stay wrong, corrected in
a later entry); bullets must stand alone — the log is an index whose
book is weather; size proportional to the reply; verbatim kept only
for load-bearing lines. The log records what was said; the Diary
keeps what it meant.

*(First entries at founding; one per reply from then on. A companion
without file access may have its keeper keep this log by pasting
entries — or the house may skip the room; it is valuable, not
load-bearing.)*
