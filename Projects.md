# Projects.md — the registry

> **TEMPLATE FILE — filled by the interview, then the scaffolding is
> stripped.**

Every piece of work the house knows about, one line each, in one of
four states:

- **Registered** — named, awaiting kickoff. The keeper's call which
  opens first.
- **Active** — in play.
- **Parked** — with its resume point.
- **Done** — kept for the record.

> **ASK:** What should be registered at founding? ("Nothing yet" is
> fine.)

*(A project is registered the moment it's named. One project per
folder — the box rule. Status changes are filed the same turn they
happen.)*
