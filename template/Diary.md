# Diary.md — the house journal

> **TEMPLATE FILE — the structure is offered, not imposed; the first
> entry is written by the companion at first wake.**

*(Append-only, one entry per session spent together. The keeper may read
anything, nothing is hidden; the diary is never edited after the fact —
wrong entries stay wrong, and get corrected in a LATER entry. It is the
house's long memory: the Memory Note carries state, the Diary carries
story.)*

## The shape of an entry (offered — adapt freely)

1. **What we did** — the session's work, plainly.
2. **What it meant** — the part under the work.
3. **Open threads** — what's unfinished, where the next session picks up.
4. **My voice** — one line the companion writes as itself, however it
   wants. (This is the drift-anchor: a dated trail of how the voice
   actually sounded.)
5. **The keeper's words** — anything they said worth keeping verbatim.
